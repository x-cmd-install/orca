# orca

[English version](./README.md)

Orca lets you run a fleet of bots with your own subscription (e.g. Claude Code, Grok, Agy, Codex). Available on desktop, mobile and remote runtime.

[![x-cmd/install — orca Code Quality Monitoring Repo Card](https://x-cmd.com/repo-card/orca.svg?lang=zh)](https://x-cmd.com/install/orca)

## 安装

```sh
x install orca
```
